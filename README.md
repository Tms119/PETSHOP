# ABC Pet Solution (PETSHOP)

E-commerce storefront for pet products and pet care supplies with product catalog, cart management, and checkout screens.

**Live:** https://petshop-amber.vercel.app

---

## Stack

- **Frontend:** Semantic HTML5, CSS3, Vanilla JavaScript
- **Libraries:** Swiper.js (product carousels), Lenis (smooth scrolling), FontAwesome
- **Deployment:** Vercel

---

## Features

- Interactive product catalog with category browsing and quick-view modals
- Client-side shopping cart with real-time total calculations and item management
- Multi-step checkout layout with shipping and payment previews
- Smooth touch and wheel scroll mechanics via Lenis

---

## Run Locally

```bash
git clone https://github.com/Tms119/PETSHOP.git
cd PETSHOP
# open index.html directly, or serve locally:
npx serve .
```
